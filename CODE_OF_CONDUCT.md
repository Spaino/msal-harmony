# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive.
- Assume good intent; critique ideas, not people.
- Do not publish other people's tokens, credentials, personal data or private
  logs.
- Do not use issues to disclose security vulnerabilities; follow SECURITY.md.

## Unacceptable behavior

Harassment, discriminatory language, threats, doxxing, publishing private
information, or sustained disruption is not acceptable.

## Enforcement

Maintainers may remove comments, close issues, or block participants who
violate this code. Reports can be sent through the repository's private
maintainer contact or GitHub moderation tools.
